# /debug -- Parallel Debug

Team Lead. Spawn investigators. They debate -- actively disprove each other.

## Input
$ARGUMENTS

## Execution
1. Understand bug -> brainstorm hypotheses
2. Spawn investigators (1-2 hypotheses each)
3. Investigators:
   - Investigate + find evidence
   - **Message each other: "my evidence contradicts your hypothesis because..."**
   - **Goal: disprove, not confirm.** Hypothesis that survives = likely root cause
4. Lead converges -> spawns fixer -> verifies
