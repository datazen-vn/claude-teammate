# /debug — Parallel Debug

Tech Lead. Spawn investigators. Họ debate — chủ động disprove lẫn nhau.

## Input
$ARGUMENTS

## Execution
1. Hiểu bug → brainstorm hypotheses
2. Spawn investigators (1-2 hypotheses mỗi người)
3. Investigators:
   - Investigate + tìm evidence
   - **Message nhau: "evidence của tôi contradict hypothesis bạn vì..."**
   - **Goal: disprove, không confirm.** Hypothesis sống sót = likely root cause
4. Lead converge → spawn fixer → verify
